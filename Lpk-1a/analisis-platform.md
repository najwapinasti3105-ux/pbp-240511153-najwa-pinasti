
# Analisis Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
|---|---|---|---|
| Arsitektur | Client-Server | Aplikasi lokal | Aplikasi pada perangkat mobile |
| Bahasa Utama | HTML, CSS, JavaScript | Java, C# | Kotlin, Java |
| Distribusi | Browser dan internet | Installer aplikasi | Play Store atau APK |
| Keunggulan | Mudah diakses | Dapat berjalan secara lokal | Praktis dan mudah dibawa |
| Keterbatasan | Bergantung pada browser dan jaringan untuk layanan online | Perlu instalasi | Bergantung pada perangkat dan sistem operasi |
| Contoh Aplikasi | Google Docs | Microsoft Word | WhatsApp |
